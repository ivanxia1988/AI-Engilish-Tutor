## 产品边界

Teeko 是面向中国孩子的英语老师，橙色小麻雀是唯一的老师角色。原 PRD/设计目标为10–12岁；2026-10-31 用户明确将年龄范围扩为8–13岁，按8–9、10–11、12–13岁分档。当前原型已调整档案与年龄标识，各年龄段的正式课程和教学适配仍需后续验证。2026-10-30 用户明确：产品是适配电脑和平板的浏览器网页，不是 iPad App，主要操作应一屏内完成。1194×834 iPad 图作为视觉参考，同时检查常见笔记本尺寸。一个账号对应一个孩子，使用预处理并人工校对的内置课程。v1 的免费定位不等于无限使用。

目标：孩子能理解说话轮次、愿意主动开口并自主回来上课；家长能了解学习结果。开口次数、回访率、延迟和成本等数值是待验证目标，不是已证明的效果。

新方案不包含用户上传课本、多孩子账号、付费版本、海外版、外教协作、手机端和作业批改。现有原型的相关入口不因规格导入自动删除，应在具体迁移任务中处理。

## 状态与动作约束

- 连接、老师音频、孩子音频、后台任务和页面标记分别建模，再映射六种可见状态；不能只靠一个按钮状态表达所有生命周期。
- 暂停、结束、断线期间不继续推进旧任务。新连接恢复的是持久化进度，不是无条件重播全部指令。
- 动作应能关联所属会话、课程页、任务版本和完成回执；具体字段和接口在实现计划中冻结，本文件不定义新的供应商 API。
- 所有页面动作基于内置元素坐标，叠加标记不改变图片布局；实际执行完成后才能告诉老师“已圈出 / 已翻页”。
- GPT-Live 和 Qwen 使用不同协议，保留 provider adapter；原稿事件/API 表属于需复核的技术材料，不据此撤回已经验证的现有适配。
- 原稿希望服务端掌握编排和敏感控制；当前 README 明确未接 sideband，此能力列入实施缺口，不能称为现状。

## 非功能验收与证据

前端审阅入口 `/prototype` 预览27个有效页面状态，课堂与报告等仍为模拟；设置的手动静默连接检测复用真实服务与认证，音效为本地Web Audio。未采集麦克风或摄像头。设计与实施说明见 [原型设计](../../plans/2026-10-30-frontend-prototype-design.md) 和 [原型计划](../../plans/2026-10-30-frontend-prototype.md)。网页布局的桌面浏览器核验不能代替平板真机语音测试。

目标 iPad 真机检查权限、回声、插话、横竖屏切换、后台恢复和长连接；合成音频或桌面自动测试不能替代孩子试用。高亮提前 ≤200ms、停声 ≤500ms、开课检查约 3 秒、报告生成时间等均保留为待验证目标，具体测量边界见待决定事项。

原稿无家庭试用 A/B 级证据；不得将其成本估计、留存目标或供应商比较写成已验证结论。课件、隐私文案与部署服务的适用要求在实际发布前核对，不通过导入文档声明已完成。
