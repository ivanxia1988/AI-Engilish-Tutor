# 教师智能体管理后台

用户2026-11-01确定后台是独立网站入口，当前主域teeko.app，对应规划admin.teeko.app。部署仍共用Railway Node/PG；登录身份、Cookie、Origin与学生端隔离。本机用独立后台端口验收，不表示域名已上线。

## 页面与组合

导航为概览、教师智能体、模型配置、用户与使用、教材管理。教材只预留规划，不开发上传/解析。桌面和平板以内部页签/列表滚动保留主要保存/发布动作，不恢复原型外框。

模型配置保存名称、服务、用途（实时对话/教学判断/视觉）、模型ID和启用状态；不接收密钥、任意URL。通义实时使用当前适配器已验证的三种ID，原生视觉不需另绑定；GPT Live可绑定独立OpenAI教学判断与视觉模型。凭据已配置不代表任意模型已通过实测。

用户后续要求动态密钥：已保存模型另有“模型密钥”区，显示单模型/环境默认/未配置状态；API Key为不回填的密码输入，通义填本次对应的工作空间和地域。密钥独立保存后清空输入，后续请求/重连生效，无需为了换key重发模型ID。恢复环境默认二次确认，取消为默认、Esc关闭；并发冲突需重新读取。保存模型期间禁用凭据，凭据写入期间锁定元数据；未保存新模型先保存。切模型丢弃旧请求，不将敏感字段写本地存储。权限/数据保护见TK-R-032。

智能体编辑分基本信息、主提示词、教学策略、模型与声音、预览与试教。默认模板为有目标的陪伴式教学。三个英语水平分别配置句长、老师短句数、追问深度和思考时间；全局设置提示上限、发散倾向/提醒轮数、纠错方式及调整支持所需证据数。思考时间/追问深度通过教学指令执行，不冒称VAD硬计时。

提示组合：固定课堂规则→智能体主提示词→当前有效英语支持等级的策略→用户语言/风格/声音偏好→不可信的本课目标与当前活动/真实反应。预览显示最终组装全文，主提示词可编辑；合理同义表达及自选内容由同供应商语义判断确认，不再只认预设词句。应用保留真实进度、时限和结束控制。

草稿保存与发布分开。发布确认后生成不可变版本，线上选择任一智能体的某次发布；支持回到历史发布。已有课堂冻结开课时配置，修改草稿/模型/线上版本不影响它。失效或跨用途模型绑定需明确显示并重选，不能用空选择掩盖旧ID；失效绑定禁止发布。

试教使用明确合成的孩子档案和文字输入，调用所选路线的教学判断模型，展示判断、原因、建议回应和下一步；不建立真实儿童课堂或伪造语音。网络/模型未配置或失败显示真实不可用，迟到试教结果不得覆盖新输入。

## 独立管理身份

专用用户名/密码登录，不走学生邮箱/邀请码。管理员会话为独立HttpOnly、SameSite=Strict、host-only Cookie；退出后台不退出学生端。无公开注册或provision接口，运维命令通过环境输入创建/更新管理员。内部运营账号不计入真实注册用户和使用统计。文档、前端或日志不得保存真实密码。

## 数据口径

概览支持7/30天，Asia/Shanghai日界线。注册数是实际学生账号，建档是profile；活跃和总时长取期间PG已结算ledger，重连不额外计课。分服务时长是本期新开课堂的累计已结算时长，和跨日ledger口径分开注明。用户表分页显示必要的账号、建档、课堂次数、已结算时长和最近上课时间。无真实供应商账单时不虚构费用。

## 交互验收

有实际的加载、错误、空列表、版本冲突、发布/回退确认与未保存离页保护；对话框默认取消、Esc可关闭，键盘焦点可见。管理员页面SSR守卫和API均验证独立会话/权限，普通用户直接访问不获得后台数据。关联TK-R-030/031、TK-AC-042/043。
