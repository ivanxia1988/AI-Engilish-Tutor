## 当前布局与交互（2026-10-31用户审阅决定）

- 适配电脑和平板，教材居主位；右侧上下排列老师与孩子的矩形视频窗口，默认孩子头像，不申请摄像头。
- 新增用户提供的[课堂参考图](../references/2026-10-31-classroom-reference.jpg)：借鉴左侧大教材、右侧双窗口、蓝紫色共享课堂底色；不将图片中的人物或品牌直接用于产品。
- 老师沿用Teeko原SVG，以近景构图与室内背景营造会议感；双方名字、轮次、独立连接状态可见，连接详情可点开。
- 底部紧凑工具栏：指针、画笔、撤销；取消独立圈选、橡皮、颜色、清空。右侧暂停/结束。课本标记按相对坐标叠加，不重排文字。
- 按最新审阅暂时取消老师窗口“慢一点”，同时移除第一课对应点击引导。无字幕、中文、重说或语速选项菜单；暂停仅有继续/结束。
- 摄像头关闭或不出镜不暂停；11改为持续无回应、环境嘈杂、交流不清楚三种互动暂停。检测与阈值仍待实现。
- 退出防误触：点结束仅弹确认，默认突出并聚焦继续，确认结束为次要危险操作；Esc返回。未结束时刷新/关闭注册原生离开提醒，完成后撤除；浏览器与平台决定提示能力。
- 五种结束原因：主动中途结束、内容完成、课时时间到、单课硬上限、每日上限。仅主动结束可取消；重连/暂停中取消回原状态。
- 每课独立，无单元完成和下一单元；结束后进入本次小结，报告默认整理中，可能需要几分钟。
- 增加可点击的图片/词卡任务、圈选答题、老师标注、答对/再试反馈、Teeko鼓励、短烟花及临时贴纸；不设积分榜。课堂情景可以模拟“讲得好”。
- 短音效本地生成，可在设置试听、课堂开关；减少动画仅显示静态鼓励。暂停/换题/离开取消过期反馈或未完成手势。
- 课堂网络质量、口语表现、报告和自动暂停仍是情景演示；设置中手动连接检测为真实静默会话，课堂点选/圈选为本地交互。

## 后续真实接入约束

| 事项 | 实现约束 |
|---|---|
| 实时语音 | 默认免按键插话，按住说话仅为降级备选；状态与嘴型由真实事件/音频驱动。 |
| 双方连接 | 分别跟踪老师服务和孩子链路，未测状态显示未知，不能用假延迟或假丢包。 |
| 标注和讲解 | 模型动作仍按SPEC校验元素、回执、版本；本地笔迹不能代表模型已识别。 |
| 暂停 | 阈值需要真实音频验证；短暂思考不等于无有效互动，恢复网络也不能解除原噪声暂停。 |
| 异步报告 | 前端小结与后台报告独立，完成信号到达前不显示“已准备好”。 |

## 页面验收参考

- 分别检查默认、建连、权限拒绝、倾听、处理、老师发声、断线及重试状态。
- 连续圈选、处理中再次操作和课堂结束后的迟到结果有明确处理方式；错误后可继续使用。
- 在目标 iPad 检查横屏、竖屏提示、后台恢复和可点区域；旧手机布局不属于 P0 目标。
- 键盘操作不抢占输入框中的空格；焦点可见，状态有文字提示，减少动画偏好生效。
- 验收场景需随实际实现补充测试，本文件不表示以上新交互已经上线。

## 2026-10-31补充审阅

笔迹必须覆盖教材插图、词卡和任务条。教材内部独立叠放，画笔层20高于任务条7，弹窗仍覆盖整个教材；指针模式笔迹不截获点击。同一画笔可手绘闭合圈答题。课堂头部不显示供应商和共享课本标签，服务选择仅在设置。互动暂停用老师第一人称说明沉默、噪声或交流不清，并给简短恢复指引。
