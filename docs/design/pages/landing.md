# Teeko 陪学分享落地页

## 当前设计与范围

2026-10-31用户确认采用第二版视觉稿，并要求实现。定位为小红书个人IP的延伸：爸爸在陪孩子学英语的过程中摸索方法，再结合自己的AI能力做成小工具，邀请有需要的家庭一起试用和交流。文案不用强营销、虚构见证/效果、用户量或免费承诺。

已实现入口`/prototype#00`。这是可滚动长页，不受应用/课堂主要动作一屏完成规则限制。原有真实课堂`/`不变；正式根路径、真实账号和邀请码发放仍待Railway后端迁移。关联[TK-R-024/025](../../specs/teeko-v1/spec.md)、[TK-AC-036/037](../../specs/teeko-v1/acceptance.md)。

## 内容与视觉

1. 首屏：“一个爸爸的英语陪学尝试”“陪孩子学英语时，我做了一个小工具。”；父亲第一人称介绍缘起。主操作填写邀请码，次操作先看看怎么用，登录独立。
2. 课堂示意：海边教材、原Teeko小麻雀老师、照片质感的AI虚构儿童Alex；可点画笔/贝壳圈出示意并撤销。标明课堂示意、人物AI生成，不采集音视频，不建立语音连接。
3. 一点想法：阳光下的陪学笔记场景；先听孩子说完、卡住换问法、留下具体反馈。仅使用用户已提供的背景，不编造家庭故事或老师资质。
4. 怎么用：选话题→看图/开口/画画→小结。报告为带有提示归因的示例，详细报告整理后查看。
5. 一起试试：邀请码表单。空码、错误、过期、停用、已使用反馈明确；成功后进入01邮箱验证码注册。已有账号仍可密码登录。
6. 家长问题、最小页脚和协议入口。

奶油白、深蓝、少量青绿和橙色，减少装饰和口号；局部插图与照片独立加载，文字/按钮/表单为真实组件。使用原Teeko SVG保持角色一致。电脑双栏、较窄视口堆叠，长内容自然滚动；导航滚至本页区块而不改变原型hash，支持键盘焦点和减少动画。

## 邀请码与原型边界

- 当前仅内存示例码：外层“示例邀请码”审阅按钮说明有效/过期/停用情景。正式产品表单不展示示例码或内部说明。
- 同一示例码完成一次注册后即不可用于第二账号；验证入口不消耗名额，离开注册撤销短期证明。
- 01中的注册入口同样要求邀请码，发送注册码和完成密码设置也检查邀请证明，登录和找回不重新要求邀请码。
- 刷新后原型账号、兑换和证明重置。不能把前端内存示例当正式访问控制。真实单次兑换、并发、停用、过期、限流与发码由Railway PostgreSQL后端实现。
