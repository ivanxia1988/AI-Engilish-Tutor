# Teeko — Design System & Build Spec (v0.3 · ages 10–12 · iPad lesson screen)

> **Read this first.** It is the single source of truth for building teeko.app.
> Tokens live in `tokens.css` / `tokens.json` / `tailwind.preset.js` (all generated by `build_tokens.py`; edit the script, not the outputs).
> **v0.3 changes (2026-10-30):** audience is now **10–12** (look must not be childish) · primary platform **iPad landscape 1194×834** · **Teeko the sparrow is the AI teacher** (there is no other teacher character) · minimal 3-element lesson screen (§7.9, §10.4, `ipad/`) · status-light tokens · radii tightened · calmer mascot sizes · captions off by default.
> Mascot artwork lives in `mascot/` (generated by `mascot/build_mascot.py`). Reference markup lives in `reference/` and renders to `mockups/`. When this doc and a mockup disagree, **this doc wins**.

## 0. Product & brand in one paragraph

Teeko teaches **spoken English to Chinese kids aged 10–12 (grades 4–6)**. **Teeko the sparrow is the AI teacher** — the only teacher on screen; there is no separate human/AI teacher persona. **Parents** find and approve it (the landing page speaks to them, in Chinese); **kids** use the app. A kid opens a lesson from Teeko's **built-in courseware** (textbook-style pages, grade 5–6 level; no uploads, no textbook import) on an **iPad in landscape**. The lesson is **voice-first**: Teeko reads, highlights and marks the page, **hands the turn to the kid**, listens, and scaffolds — the kid steers by voice (“Again” / “Slower” / “中文”), not by buttons.
**v1 is completely free.** No pricing, plans, paywalls or editions anywhere in the UI.
Tone: warm, calm, **grown-up for a 10–12-year-old** (think good study app, not a toddler game) — trustworthy for parents. Restraint stays: cream/navy surfaces, one orange signal per view, no gradients, no confetti storms, no streak pressure.

Logo: V1 — wordmark first ("Tee" navy `#1F2A44` + "ko" orange `#E07A3F`, Nunito Black), then the sparrow head icon at cap height to the right.

### 2.3 Usage ratio (per screen, by area)
**~60% cream/white surfaces · ~25% navy (text, primary UI) · ~10% orange (one accent CTA, turn state, mascot) · ~5% teal (live, links, focus).**
Orange is a *signal*, not decoration: if more than one thing on screen is orange-filled, one of them is wrong.

### 2.4 Contrast rules (WCAG 2.2 AA; see `contrast.json`)
- Body text ≥ 4.5:1, large text (≥24px, or ≥18.66px bold) and UI/graphics ≥ 3:1.
- **Never** use orange-500 for text on light backgrounds (2.82:1) or white text on orange-500 (2.99:1). Text **on** orange = navy-900 (4.77:1). Orange **text** on light = orange-700 (5.37:1). Display-size headline accent may use orange-600.
- Listening mic: white icon on teal-500 is a 3:1 UI graphic — do not put small text on teal-500; labels go in teal-700 on teal-100.
- Chinese helper text uses ink-500 minimum (5.2:1 on cream-100). Never ink-400 for readable copy.
- `ink-200` borders are decorative only; interactive control borders use `--tk-border-input` (3.24:1).

## 5. Iconography & illustration

- **Icons:** Lucide, stroke 1.75 (2 at ≥28px on kid screens), round caps, `currentColor`. Sizes 20 / 24 / 28 / 40 (mic). Never filled except the star.
- **Mascot:** the only brand illustration. Always use the SVGs from `mascot/svg/` — never redraw, recolor, stretch, flip the logo icon, or apply CSS filters (exception: `opacity` .42 for the paused state). One mascot per view region. Minimum full-body size 96px; under that use the head icon.

## 6. Mascot — Teeko the sparrow (full body)

### 6.1 Construction
Vector, flat, no strokes on the outline; all parts on a **240 × 300** grid (handoff pose 290 wide to fit the held mic). Head circle r76 at (120,112), body ellipse 72×62 at (120,202), cream face/belly, two-tone tufts, two wings, tail to the right, orange feet, soft ground shadow (navy 12%).

| Group / id (in every SVG) | Notes |
|---|---|
| `.ground` | Shadow; keep under the feet, scale with bob if animating |
| `.sparrow` | Root. Animate idle bob here (2px max) |
| `.feet` `.tail` `.tuft` `.body` | Static per pose |
| `.wing.wing-l` / `.wing.wing-r` | Rotate around the shoulder for gestures |
| `.head` | Rotate/bob around (120,176) |
| `.eyes.eyes-open` / `.eyes.eyes-blink` | Toggle for blinks |
| `.cheeks` | Static |
| `.mouth-slot` → `#mouth-closed` `#mouth-small` `#mouth-wide` `#mouth-oo` | Exactly one has `.on` (rig) |

Views (turnaround): `view-front`, `view-three-quarter`, `view-side`, `view-back`. Use front or three-quarter in UI; side/back are for animators.

### 6.2 Poses → when to use

| Pose file | App state | Where |
|---|---|---|
| `pose-idle-listening.svg` | idle; **kid is speaking** (mic `listening`) — leaning in, wing to ear | rail, lesson header, empty states |
| `pose-talking.svg` | **Teeko is speaking** (mic `idle`); pair with lip-sync | rail, landing step 1 |
| `pose-handoff.svg` | **Your turn** (mic `turn`) — holds the mic out | rail, landing hero, step 2 |
| `pose-thinking.svg` | mic `processing` | rail |
| `pose-celebrate.svg` | 3 stars, lesson complete, final CTA | feedback, landing final band |

Swap poses with a 160ms cross-fade + 4px rise (`--tk-ease-standard`); the handoff swap uses the 640ms spring (§7.2).

### 6.3 Visemes (mouth shapes)

| id | Shape | Use for (English phonemes) | Amplitude rule |
|---|---|---|---|
| `closed` | beak shut | m, b, p, silence, pauses | RMS < 0.08 |
| `small` | slightly open | e, i, s, t, d, n, k, g, l, r, consonant clusters | 0.08 ≤ RMS < 0.32 |
| `wide` | open + tongue | a, æ, ʌ, ɑ, aɪ, aʊ (loud open vowels) | RMS ≥ 0.32 |
| `oo` | round | o, u, w, uː, oʊ, ɔɪ | phoneme hint, else 15% random from `small` |

**Lip-sync driver (production):** sample the TTS audio level every **80ms** (WebAudio `AnalyserNode`, RMS normalised 0–1, light smoothing 0.6/0.4), pick a viseme with the thresholds above, and **hold each viseme ≥ 80ms** (no flicker). If the TTS provider returns phoneme/viseme timestamps, map them through the table instead and ignore amplitude. Return to `closed` within 120ms of audio end. Reference: `mascot/talking-demo.html`.

**Talking loop (no audio, e.g. previews/loading):** `svg/teeko-talking-loop.svg`, pure CSS:
- 16 frames × **90ms** = **1440ms** loop: `closed small wide small oo small wide wide small closed oo small wide small closed closed` (`steps(1,end)` visibility keyframes)
- head bob **720ms** ease-in-out (translateY −2px, rotate 2°), origin (120,176)
- blink every **3600ms** (93–97%)
- left wing gesture synced to the loop
- `prefers-reduced-motion`: no bob/gesture; mouth still switches (it carries meaning) but at most every 180ms, or static `closed` if the user opted out.

**Lottie (optional for native apps later):** export each pose as a layer comp with the same group names; visemes as 4 hidden layers in a `mouth` precomp toggled by markers `closed/small/wide/oo`; 24fps, 240×300, no effects/masks except the two clip paths. Web v1 ships SVG + CSS (smaller, crisp, themeable).

### 6.4 Rules
- The mascot never says anything negative and never shows red or a "wrong" face.
- Not idle-animated when nothing is happening (one blink every 3.6s is OK).
- On the iPad lesson screen the mascot lives **only** in the 168px avatar disc (top right); its state is pose + glow + ring shape, **never a text label**.
- Mascot orange `#EE7A30` ≠ UI orange; it doesn't count toward "one orange fill per view".
- Head icon (`mascot/teeko-head-icon.svg`) = app icon, favicon, chat avatar, logo.

## 7. Components (states are mandatory)

All interactive elements: visible `:focus-visible` = `--tk-shadow-focus`. Hit targets per §4. Transitions use `--tk-duration-fast` + `--tk-ease-standard` unless noted.

### 7.1 Button `.btn` (pill)
Sizes: `--sm` 44h (parent pages only) · **md 56h** (default) · `--lg` 64h, Nunito 800 18px (kid primary). Icon 24px.

| Variant | Default | Hover | Active | Disabled |
|---|---|---|---|---|
| primary | navy-900, cream-100 text | navy-800 | translateY(1px) scale(.98) | cream-200, ink-400 |
| accent (**1 per view**) | orange-500, **navy-900** text | orange-300 | same | same |
| secondary | transparent, navy text, 1.5px navy-300 border | navy-50 | same | same |
| cream (on navy) | cream-100, navy text | white | same | — |
| ghost | transparent | cream-200 | same | ink-400 |

### 7.2 Mic `.mic[data-state]` — web only (80px, icon 36px)
> iPad lesson screen: **no mic button**. The child window (§7.9) is the turn signal; the mic is always open during the kid's turn.

| state | Visual | Mascot pose | Label under mic |
|---|---|---|---|
| `idle` | white, 2px navy-300 border | talking (while Teeko speaks) / idle | 按一下说话 |
| `turn` | orange-500, navy icon, `shadow-turn`, pulse 1600ms | **handoff** | **按住说话** |
| `listening` | teal-500, white 5-bar wave (live level) | idle-listening | 我在听… |
| `processing` | navy-100, navy-500 dots | thinking | 想一想… |
| `disabled` | cream-200, ink-400 | idle | 没听到声音，检查一下麦克风 |

State machine: `idle → (Teeko speaks, lip-sync) → turn → listening → processing → feedback (stars) → turn | next line`. Kids can **press-and-hold** or **tap-to-toggle** (setting; default tap-to-toggle). Ignored turn for 20s: pulse stops, mascot repeats the prompt once, softly. Desktop: Space hold-to-talk, Esc skip.

**Handoff (640ms, `--tk-ease-spring` .34,1.56,.64,1):** 0ms Teeko finishes (talking pose, mouth → closed) → swap to handoff pose with a 4px pop → speech bubble “轮到你啦！ + the English line” slides in (200ms, 80ms delay) → at 640ms mic switches to `turn`, pulse starts after 200ms. Reduced motion: instant swap, no pulse, static halo. Never motion- or color-only: the bubble text is always shown and announced (`aria-live="polite"`).

### 7.3 Stars `.stars` (replace scores)
- Always 3 slots; 1–3 filled (`--tk-star`), the rest `.star--empty`. **Never show 0 stars** — a failed attempt shows “再试一次” + the mascot re-modelling the line.
- Headlines: 3 = 太棒了！ (celebrate pose) · 2 = 说得真好！ · 1 = 再试一次就更好啦.
- Pop-in: each star scales 0.4→1 with spring, 90ms stagger; reduced motion = fade.
- Sizes: 40px (feedback), 20px `.stars--sm` (lists, lesson cards). Totals shown as a star badge in the top bar (navy number on cream-100 pill).
- No numeric scores, percentages, leaderboards or streak counters for kids. Parents can see progress (stars + words) on a future parent view.

### 7.4 Per-word feedback `.say`
Kid's line in `lesson-line` type. `.ok` = success-700 text; `.again` = orange-700 text + orange-300 wavy underline. No red. One tip max, in Chinese, with a simple sound hint (“favorite 读作 FAY-vuh-rit，中间轻一点”) and a 再听一遍 button.

### 7.5 Speech bubble `.speech`
White, radius 16, shadow-sm (web only — the iPad lesson screen has no speech bubbles), tail toward the mascot's beak (`.speech--left` flips). First line Nunito 800 20px (Chinese instruction or English line), optional second line 15px ink-500. Max ~16 Chinese characters per line.

### 7.6 Lesson page & tools
- White page, radius 12 (md), `shadow-page`, centered on cream-100 (iPad: 820×786, see §10.4).
- Tool switch `.seg` (52px buttons, labels with icons): **点一点** (tap a word/line → highlight + Teeko reads it + one-line Chinese meaning) and **圈一圈** (draw a circle → stroke draws on 320ms → Teeko reads the circled part and offers 跟我说).
- No pan/zoom tool for kids; pages are designed to fit. Pinch-zoom allowed by the browser on mobile.
- Label `内置课件` content is built in; there is **no upload, import or camera** entry anywhere.

### 7.7 Cards, chips, inputs
Cards: white, 1px cream-200, radius 16 (lg), padding 24. Chips: 36h on kid screens. Inputs appear only on parent-facing pages (future account), 56h.

### 7.9 iPad lesson status lights (v0.3) — `ipad/lesson.html`

Three elements only: **textbook page** (the single visual focus; all marks are drawn on it) · **Teeko avatar** (top right, 168px disc) · **child window** (bottom right, 232×174; avatar by default, camera only if a parent enabled it). Status is never colour-only — each state also changes **shape or motion**.

| State | Where | Colour token | Shape / motion | Pose |
|---|---|---|---|---|
| Teeko speaking | avatar disc | `--tk-status-speaking-glow` teal-300 glow + 1.5px teal-500 ring | **solid outer ring breathing** 1600ms; beak lip-sync | talking |
| Your turn | child window | `--tk-status-turn` orange-500 | **solid 3px border + halo breathing** 1600ms; volume meter pill (mic + 7 bars) | handoff (holds out the mic), disc glow off |
| Child talking / listening | child window | `--tk-status-listening` teal-500 | 3px border, **bars move with live level**, halo static | idle-listening |
| Thinking / delegating | avatar disc | `--tk-status-thinking-glow` amber-500 glow; dots `--tk-status-thinking` warning-600 (3.6:1) | **3 dots** under the disc, 1200ms stagger | thinking |
| Paused | avatar + whole screen | `--tk-status-paused` navy-300 | **dashed ring, pause badge, mascot opacity .42, no motion** | idle |
| Reconnecting | avatar disc | `--tk-status-reconnecting` navy-500 | **rotating dashed ¼-arc** 1400ms linear, mascot opacity .6 | idle |

## 11. Do / Don't
- **Do** keep one orange fill per view (hero CTA or turn mic). **Don't** add more orange buttons.
- **Do** use stars and kind Chinese tips. **Don't** use numbers, red, “错”, timers or streak pressure.
- **Do** use the mascot SVGs and pose table. **Don't** redraw, recolor or animate it when idle.
- **Do** keep copy short: ≤ 16 Chinese characters per kid instruction. **Don't** put paragraphs on kid screens.
- **Don't** show pricing, plans, paid editions, uploads, textbook import or Chinese-for-foreigners anywhere.
- **Don't** add gradients, glass, extra illustration styles or new colors outside §2.2b lesson art.
- **Do** keep the iPad lesson screen to three elements (page · Teeko · child window). **Don't** add subtitles bars, text status labels next to Teeko, quick-action buttons, stars bursts or confetti.
- **Don't** signal a state by colour alone — pair it with ring shape, dots, border or motion (§7.9).
- **Don't** make it look babyish: no oversized mascot, no rainbow, no bubbly 26px+ radii; target 10–12.
