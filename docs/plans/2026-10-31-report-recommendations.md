# 课堂记录驱动的练习建议

**Goal:** 将13报告页“在家怎么聊”改为与本课不熟悉、纠正记录对应的练习建议。

**Architecture:** 保留现有三个页签和报告状态，在原型中以两条明确的示例课堂观察展示“课堂表现→老师处理→随后表现→具体练法”。简版记录不足时显示空态，不补造诊断；正式报告必须由实际课堂证据支撑。

**Tech Stack:** 现有React / TypeScript / 作用域CSS，无新增服务或依赖。

## 实施

1. 修改`components/prototype/prototype.tsx`：页签更名、两条具体建议和记录不足空态，删除通用家长建议；报告标题移除无用说明。
2. 修改`components/prototype/prototype.css`：两列卡片、紧凑证据行、练习区，保证1176×749及1024×768一屏可达。
3. 同步`docs/specs/teeko-v1/spec.md`的TK-R-102与`acceptance.md`，原PRD和素材不改。
4. 运行`npm run typecheck`及既有原型测试；浏览器核对完整/简版/生成中，检查布局并保存截图。本次只调整前端展示，未接课堂数据分析或报告生成。
