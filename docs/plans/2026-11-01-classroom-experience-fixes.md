# 整课体验修正与实施记录

**目标：** 按用户真实验收，简化画面分享，弱化常驻提示，允许自然对话，修复短课误结束，补足事实小结和回看入口。

**架构：** 保留Node/PG及双供应商媒体结构。共享课程以版本化manifest发布；服务端独立校验答题证据，教学对话不等于成绩。小结直接从持久化snapshot派生，不引入新模型调用或伪造异步报告任务。

**技术：** Next/React、TypeScript、PostgreSQL、既有WS适配、node:test/JSDOM。

## 依据与根因

用户已确认摄像头能看到，要求开摄像头即分享、提示可折叠、答对才奖励，并反馈没有课后总结、课程很快结束、老师总拉回教学主线。

只读本地元数据看到一条v1内容完成仅171秒；其他短记录是manual，不能归因相同。代码v1只有七个短活动，最后advance立即结束；原任意目标水果关键词匹配和delegate中的next/another片段还会把闲聊误当答对/跳过。runtime和切题cue要求立即提下一题，强化机械感。原小结仅统计数量、没有活动建议，课表没有历史入口。

## 文件所有权与顺序

1. `classroom-experience-ui` worktree：课堂/相机/样式/UI测试，先修改失败验收再实现自动分享、提示折叠、奖励证据和小结呈现。
2. `classroom-conversation-fix` worktree：runtime/service/catalog及教学cue/测试，先复现闲聊误推进，再引入纯分类器与v2。原v1逐字保留发布校验。
3. 主分支：`lib/classroom-summary.ts`纯函数及测试；`courses`历史契约/有界查询/界面/隔离PG测试，顺序集成服务文件。
4. 独立只读审阅：发现题外“I like dinosaurs”等仍回retry，新增红测并修复。合成浏览器验证发现短屏课程介绍重叠，调整紧凑布局后复验。

## 最终行为

- 点击开启相机请求权限即同意分享；预检开启后等语音连接，课中直接自动分享。错误不循环，手动重试；关闭/暂停/结束/断线和晚授权均清理。原视觉路由、鉴权、时效、字节/频率边界不变。
- 课本下的“课堂提示”默认折叠，可展开；它不是逐字转写。只有新答对outcome和新correct反馈一起出现才奖励，普通聊天/观察/跳过/回放不奖励。
- 课堂允许顺着孩子兴趣接话和追问，闲聊不判错、不跳题、不自动完成。明确水果命名/选择、邀请和带物表达才确认；否定、错水果、多水果歧义仍不通过。
- picnic v2增加自选表达、邀请、准备场景和最终自由交流；完成九个活动后仍能聊，不自动挂断。查看小结/结束或原保护时限生效；不凑参考10分钟、不改变15分钟上限。旧v1会话与checkpoint保留，重新开课选v2；不覆写旧课版本。
- 课后展示实际完成、提示后完成、跳过建议和下一步；无证据明确记录不足，不推断掌握、发音或注意力。最近六节已结束课堂按结束时间倒序，每页三条，可回看；查询及详情保持账号所有权。异步AI详细报告仍未实现。
