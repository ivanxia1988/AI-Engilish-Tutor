# 视频课堂布局设计与实施计划

**Goal:** 用户确认“教材为主，右侧展示老师和孩子的视频窗口”；把漂浮圆头像改为有在场感的视频课堂，电脑/平板一屏操作。

**Architecture:** 继续使用独立 `/prototype`，修改现有课堂06–11/18–20的共享组件。教材为共享区域，右侧两个矩形参与者窗口；加入本地标注工具和独立连接状态；按最新反馈精简暂停、结束和报告流程，不接真实媒体。

**Tech Stack:** 现有React / TypeScript / CSS / Lucide与原Teeko SVG，无新依赖或网络调用。

## 已确认的视觉方向

- 教材占主要宽度；右侧参与者区同时保留老师和孩子窗口，常见笔记本中上下排列以保证课本宽度，老师窗口更突出。
- 老师采用矩形镜头构图和较大的近景Teeko，配柔和房间背景、姓名条、语音波形及发言边框。沿用原角色素材，不替换为真人。
- 孩子窗口显示头像与关闭摄像头状态；摄像头关闭或不出镜不暂停。11改为有效互动暂停：长时间无回应、持续噪声或无法有效交流；阈值与真实声音检测待接入。
- 顶部提供共享课本上下文；底部小型操作条提供本地画笔/圈选/橡皮/撤销/清除，以及暂停、结束。老师窗口直接提供“慢一点”提醒；按最新反馈移除字幕、重说和中文菜单。
- 讲话动画、波形与课堂状态均为原型演示，不能描述为实际音视频会议已经接通。

## 实施步骤

1. 修改 `components/prototype/prototype.tsx`：重组课堂框架与参与者窗口；老师/学生各自有连接状态与详情，状态由外层审阅工具模拟，不伪造真实网络测量。
2. 修改 `components/prototype/prototype.css`：限定到新课堂类名，适配1176×749、1194×834和1024×768；检查课本可读性、边界、减少动画和焦点。
3. 修改 `docs/design/pages/classroom.md` / `docs/design/mascot.md`、SPEC与验收，明确用户新要求覆盖旧圆盘布局；原PRD/设计源不改写。
4. 新增 `lib/prototype-annotations.ts` / `lib/prototype-session.ts` 及对应测试：标注坐标、擦除命中、结束原因、连接显示和旧页面兼容。画笔真实响应鼠标/触摸，标记只在本地保存；不接AI工具执行。
5. 中途结束需确认；内容学完、课时到、单课或每日上限分别解释且不允许继续已经结束的课堂；小结12默认报告整理中，准备好后才可查看完整报告。移除22单元完成及所有单元入口，旧22链接兼容转至12。
6. 运行 `npm run typecheck`、相关Node测试和`npm run build`；浏览器验证标注、参与者连接、暂停/恢复、慢一点、结束分支及延迟报告。
7. 保存实际截图与验证结果，留在课堂页面供用户审阅。不开启真实摄像头、麦克风、语音或生产部署。

## 验证结果

已完成前端实施和派生规格同步；14项原型测试、类型检查、构建通过。浏览器确认本地标注、独立连接情景、精简暂停、结束原因、默认报告整理中及22兼容跳转；详细证据见[原型实施记录](2026-10-30-frontend-prototype.md)。真实网络检测、音频分析、自动暂停、模型/报告后端与媒体接入均未实施。
