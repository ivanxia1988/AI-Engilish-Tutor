# 课堂互动反馈实施计划

**Goal:** 在独立原型中实际体验点选/圈选、答对/再试、老师标注提示和鼓励烟花。

**Architecture:** 新增本地练习状态，复用classroom.resolveSelection解析标注命中；几何选择与对错判断分开。题目、答题结果与奖励事件分别建模，避免空圈/多选误判和同题重复奖励。原型模拟口语表扬，不接真实声音评估。

**Tech Stack:** 现有React / TypeScript / CSS动画 / Lucide / 原Teeko素材；后续补充Web Audio音效及复用现有实时客户端的连接检测，无新依赖。

## 设计

- 在教材原词区提供简短任务、提示和换题；点词卡、点插图或圈选均可回答。错误以暖色和具体提示反馈，不给分数、不强迫重复。
- 同一题首次答对才触发Teeko鼓励动作、短烟花及临时贴纸；课堂情景里的“讲得好”单独模拟口语鼓励，不作为真实评估或答题正确。
- 老师提示在原对象加标注，提示后完成不描述为独立掌握。圈空/圈多个先澄清，普通自由笔迹不当作回答。
- 暂停、思考、纠音、断线时停止答题和奖励；奖励不拦截操作，减少动画时只显示静态表扬。切换题目不自动判定旧笔迹。

## 步骤与文件

1. 先新增`tests/prototype-interactions.test.ts`覆盖正确、错误、澄清、提示后答对、重复点击、换题、口语表扬及几何选择，观察失败。
2. 新增`lib/prototype-interactions.ts`；扩展`components/prototype/annotation-layer.tsx`完成回调和工具选择方法。
3. 修改`components/prototype/prototype.tsx`的插图、词卡、任务行与外层情景；新增`components/prototype/reward-effect.tsx`和作用域样式。
4. 同步SPEC/验收/设计，记录用户最新奖励要求覆盖旧“不放庆祝效果”的参考约束，保留原始PRD和设计源。
5. 运行相关测试、`npm run typecheck`、`npm run build`；浏览器实测点选与圈选、错误重试、提示、换题、表扬、暂停，以及1176/1024宽度和减少动画。

## 用户补充与实现

- 参考用户提供的课堂照片，保留教材为主、右侧师生双窗口，调整为浅蓝紫课堂底色；原图存入设计references，沿用Teeko素材，不复制第三方品牌或人物。
- 用Web Audio生成短促的答对、再试、提示与庆祝音；首次操作后才创建音频资源。设置可试听和保存开关，课堂可立即静音。停止、换页、关闭音效及卸载会取消待播放声音。
- 设置增加通义/GPT Live选择，保存后在原型课堂显示服务名称。GPT Live附当前浏览器VPN/代理提示，选中或保存不会自动发起检测。
- 用户明确要求现场连接检测后，复用现有/api/status认证检查及LiveClassroomClient的probe模式，真实建立接收通道并关闭；不打开麦克风/摄像头、不发送教材或学生语音，不修改认证和凭据。连接失败、超时、缺配置和未登录分别显示结果，切换服务清理旧检测。

## 最终验证 · 2026-10-31

- 27项原型测试、npm run typecheck、npm run build及git diff --check通过。构建只有Vinext既有路由分类提示。
- Chrome实际操作点图、点词和圈选：正确奖励、错误重试、空圈/多选澄清、提示标注均可见。换题取消尚未完成的手势，避免旧笔迹误判新题；同题不重复奖励。口语表扬为单独情景，不能证明发音或掌握程度。
- 减少动画模式隐藏烟花但保留静态表扬；关闭音效后答对新增音频节点0个，重新开启后答对新增7个。试听观察到音频上下文从suspended进入running；连续试听、关闭、离开时用请求序号避免旧请求失败提示。
- 当前Chrome对GPT Live和通义各完成一次真实probe：建立实时连接后关闭，页面显示成功，未申请麦克风或摄像头。该结果只代表当时、当前浏览器环境，不保证以后或其他设备可连。
- 1176×749及1024×767检查：教材五行对话完整，工具、音效、暂停、结束与设置保存一屏可达。奖励效果与设置截图已保存。
- 课堂对话、口语评估、网络状态演示及报告仍为原型；连接检测的通过不表示原型已接入真实上课。未改原始PRD、未发布或部署。
