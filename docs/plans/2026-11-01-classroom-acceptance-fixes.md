# 真实课堂验收修正 Implementation Plan

**Goal:** 修正老师静态姿势反复切换、讲完不交接、摄像头无网页授权入口及用户报告的短时断线被显示为普通暂停。

**Architecture:** 继续既有Node/PG/受控PCM通路；单一SVG rig以实际播放能量驱动嘴型；摄像头为用户点击触发的本地预览，视频不上传、不用于视觉评判；保留服务端时限与租约，以安全枚举区分真实连接故障。

**Tech Stack:** React、MediaDevices.getUserMedia、现有WebAudio/AudioWorklet与Node WebSocket。

## 已知证据与文件所有权

- 用户课的非内容元数据：通义，累计约50.6秒，连接代次2，停在第5活动，最终主动结束；没有达到时间或内容上限。旧版不持久化停止原因，不能据此断言是哪条保护触发；不得打印孩子转写或上游错误原文。
- 头像根因：每40ms按能量阈值交替载入两张头部角度不同的静态SVG，实际没有嘴型绑定。
- avatar-fix worktree：新增teacher-avatar组件、独立CSS和回归；不改主课堂文件。
- pause-fix worktree：音频/WS/客户端、纯错误枚举与对应测试；主目录做隔离实际复现。
- 主目录：classroom-camera组件、正式课堂集成、UI测试与文档。密钥与现有账号保持不动。

## 按序验证

1. 摄像头先测试不自动请求、点击后请求video且audio:false、拒绝可重试、暂停/结束/卸载/取消晚授权停轨；实现本地预览与权限提示。运行 `node --import tsx --test tests/classroom-camera.test.tsx`。
2. 稳定rig补嘴型保持/闭嘴/交接取消/减少动画场景；真实播放队列未空时不提前交接，GPT连续静音流的交接边界如实记录。
3. WS先诊断后修根因：以受控长媒体时钟/插话/回复生命周期补失败测试，安全错误不得折成普通暂停，不放松音频背压或滥用保护来掩盖问题。
4. 用loopback隔离PG及真实通义短会话复现用户节奏，必要时仅记录错误类别/持续时长/包数量/PCM能量，不记录音视频或转写正文。无复现证据不声称根因已确认。
5. 相关测试→类型检查→Node构建→电脑/平板视觉检查；保留用户账号，重启8080，无push/部署。

## 最新产品约束

用户本轮明确要求摄像头网页授权流程，覆盖旧版“本阶段不开摄像头”：仅添加可选本地摄像头预览，浏览器已有权限时是否再次弹窗由浏览器决定。未授权、无设备、关闭或不出镜均不暂停语音课堂；不增加视频上传或模型视觉观察。

## 完成与实测记录

- 老师使用原包单rig，四嘴型跟随实际播放能量，80ms保持、静音约100–120ms闭嘴；1200ms持续静音且允许交接才抬翅递麦。通义另由真实播放队列约束；GPT持续静音PCM下仍是保守近似，不冒充供应商completed事件。减少动画保留静态轮次提示。
- 摄像头默认不申请，显式点击请求audio:false/video，授权后video.srcObject本机预览。拒绝可继续上课、预检切课堂保持流、取消/暂停/结束/断线/卸载和晚授权均清轨。独立审阅发现授权resolve与取消微任务竞态，补先红后绿的stop/dispose回归修复。
- 安全故障分类与实际播放队列回调贯穿server/client/UI。连接异常显示具体原因及“课堂连接中断”，主动暂停仍为“已暂停”；恢复需用户再次开始，不自动重开设备。
- 真实通义探针1：65秒自然媒体、645输入帧、两次合成成人发言，持续active无错误。探针2：有声中插话+两个200ms短噪声（间隔400ms），14秒发生transport_error，PG变paused，音频队列峰值99ms、无供应商error事件，最后出现tool_args.done。没有保存工具参数，不能认定真实参数必坏或唯一根因。
- 受控回归先红确证：取消、旧题或截断工具JSON会被现有JSON.parse catch当transport_error关闭媒体。现丢弃取消/过期工具，当前无效参数回unavailable不执行，单题最多一次澄清，后续不create循环；有效同题工具与音频串接继续工作。限流、0.5秒采集积压和2秒播放保护没有放宽；600帧/60秒虚拟450msbatch跨秒检查也通过。
- 修复后唯一追加真实复测：相同插话/短噪声场景35秒仍active，24秒正确成人ASR推进到下一题，348输入、230下行、141实际有声帧，队列峰值70ms、错误为空。本次没有tool_done，坏参数分支由回归证明，不能声称真实现场已再次覆盖该分支。
- 全量384项：378通过、6项需显式环境的检查跳过；TypeScript、Node构建、定向ESLint（0error，5条既有Hook/img warning）与diff检查通过。本轮PG结构未变，不重复旧账号测试代替本轮媒体验证。
- 组件视觉fixture在1440×900、1194×834、1024×767无横纵溢出；原Chrome缩放使最后高度比目标768少1px。真实CUA画笔/撤销、嘴型/交接取消、摄像头拒绝、故障弹窗与退出焦点检查通过。fixture使用合成状态/权限拒绝，没有真实摄像头授权或声音采集，不能当真机媒体验收。
