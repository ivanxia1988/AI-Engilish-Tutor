# 真实课程与课堂运行说明

本阶段在本机接通一节版本化试上课“**一起去野餐**”：正式账号→我的课程→麦克风检查→真实通义/GPT Live对话→点选/画笔互动→暂停、恢复、结束保存。无原型外框、假连接、假历史或发音分数。尚未推送或部署到Railway。

## 运行与数据

正式运行使用Next Node custom server，HTTP仍在`/api/v1`，语音单独使用`/ws/classrooms/{UUID}`。Next会为已有App路由自动注册升级处理器，因此不能将应用WS放进`/api/v1/[...path]`。`scripts/serve-node.mjs`持有两家上游主WebSocket，`ws`和`tsx`属于运行依赖。

本机已保留独立PostgreSQL容器`teeko-local-postgres`和持久卷`teeko-local-postgres-data`，真实验收数据在`teeko_local_acceptance`。已有账号与档案未清空；增加课堂表前已在`.private`内保存权限0600的备份。密钥只通过私有环境文件读入；不要将文件内容发到聊天或提交。

```sh
docker start teeko-local-postgres
node --env-file=.private/local-acceptance.env scripts/migrate-accounts.mjs
npm run build:node
node --env-file=.dev.vars --env-file=.private/local-acceptance.env scripts/run-node-framework.mjs start
```

本机入口为`http://127.0.0.1:8080/courses`。`.dev.vars`提供已有语音供应商配置；后一个私有环境文件提供本地账号数据库、固定账号保护密钥、APP_ORIGIN和邮件发件配置。默认5173仍是旧Worker开发回归入口，不能用其运行状态替代正式Node验收。

## 课程、状态与真实证据

- `course-catalog.ts`发布picnic版本1，只包含一张既有原创SVG教材和7个点选/词句活动；旧原型的六主题没有冒充成六套真实课程。改变已发布清单需要增加版本；修改图稿也应使用新的版本文件名。
- PostgreSQL为账号归属、冻结课件/档案/偏好、当前活动、结果、时长、结束原因和连接代次的事实来源。一个账号最多一节未结束课堂；中途结束后重新开课沿保留的版本内检查点继续，已经学完则可重新开始。
- HTTP动作使用UUID事件ID与预期revision，重复重放不重复推进，过期动作拒绝并重读。工具和最终转写必须匹配`classroomId:connectionEpoch:stepIndex`；结束、换题和旧连接的结果不能落到新题。
- 点选/闭合画圈由页面几何命中已知元素，服务端再按当前题校验；圈空、多个对象、未闭合笔迹不判正确。普通笔迹仅为本地标注，未上线未知笔迹视觉检查。
- 完整儿童ASR或主动输入先落库，再由应用校验当前词句，不依赖语音模型是否主动调用评分函数。否定、拒答、多水果歧义和缺少上下文均不能算正确；输入只证明词句，不证明音素、发音质量或长期掌握。
- 记录独立完成、提示后完成、跳过与未评估；跳过允许继续，不记作掌握。明确的完整Stop/Pause会暂停，Skip/换一题会跳过，不继续逼读。一般无回应/噪声自动暂停阈值仍待家庭音频研究，未用假检测替代。
- 只保留每课最近64条有界最终文字证据，区分speech/typed；不默认持久化录音或摄像头画面。GPT没有原生话轮完成事件，应用用连续有声PCM、实际低能量帧及短收尾窗口组合边界；该阈值仍需真人听感校准。

## 连接、关闭与限额

同源Origin与HttpOnly账号Cookie通过后才领取PG租约并创建上游；服务端确认供应商会话ID写入后才ready。每2秒检查登录有效性、租约与当前状态，15秒租约过期会暂停。HTTP提交后通过进程内刷新通知立即同步拥有连接的Node模块；通知只带课堂ID，状态仍从PG读取。当前按单Node实例设计，多副本需要额外owner路由。

两家分别适配事件。GPT初始规则在session.start，运行中thinking更新只传精简事实并按保守字节上界分块；必须持续发送包括静音在内的PCM推动时间线。通义要分别等待配置回执、应用response.created、response.cancel→response.done，以及VAD自动创建回复的等待窗口；不能把取消请求当已关闭，也不能让换题提示抢开第二条回复。

供应商生成快于播放时，由服务端按24kHz PCM、50ms小帧实时发送，队列最多12秒，浏览器的2秒积压保护仍保留；定时器延迟不会突发追赶。

GPT Live持续输出含静音的PCM，不能把有音频包等同老师正在发声。插话/换题先清音，再等待当前上下文回执、真实输入静音与实际低能量输出恢复播放；没有回复ID，因此仍是保守同步，可能丢句头或超时需重连，暂不承诺精确音频归属。通义同题工具反馈只同步状态，由tool_result自然续答，保留前缀声音。

暂停、结束、切换或销毁会立即停止本地麦克风与播放，关闭上游并释放租约。客户端退出后服务端仍通过心跳和硬截止清理；关闭确认与真实播放状态分别记录，服务端已有转写不代表孩子已经听完。

首批本地保护参数为单课最多15分钟、每天累计60分钟，不是产品价格或承诺的课程长度。实际活动区间按Asia/Shanghai自然日账本累计，跨日会拆分；重新连接和旧课堂恢复不能重置当天余额。这是应用课堂时长，不能当供应商最终计费秒数；生产用量对账、独立Jobs与报告任务仍未实现。

## 主要接口

| 接口 | 行为 |
|---|---|
| GET /api/v1/courses | 已发布课程、真实恢复点与当前未结束课堂 |
| GET /api/v1/classroom-options | 两家是否配置及当前教学偏好；配置存在不等于连接成功 |
| PATCH /api/v1/preferences | 保存供应商、授课语言、老师风格、声音和互动音效 |
| POST /api/v1/classrooms | 固定版本、档案和偏好后创建preflight课堂 |
| GET /api/v1/classrooms/:id | 当前账号的权威状态或事实小结 |
| POST /api/v1/classrooms/:id/actions | 受限select/hint/next/skip/pause/resume/end动作 |
| WS /ws/classrooms/:id | 受控PCM、主动输入与关闭；不接受任意供应商命令 |

所有写请求校验Origin与严格、有界JSON；新业务不使用Sites身份头，旧Sites AI接口也没有对新账号无条件开放。GET响应no-store，账号归属不能由客户端参数指定。

## 验收边界

已做真实PG、正式Next HTTP/WS与供应商短课联调，另用合成成人音频测试识别，不当作儿童真人试用。浏览器已检查1440×900、1194×834、1024×768的页面、偏好保存、键盘、退出确认、小结与返回；视觉验收未采集麦克风或连接供应商。真人麦克风、回声、家庭噪声、长时间交互和实际听感仍由用户本轮整课验收。

详细报告显示“暂未开放”，不假装后台生成。当前没有多节正式课程、学校年级/单元、单词本、相机感知、支付或完整运营后台。Railway线上仍为旧版本，未创建云PG、未推送、未部署。
